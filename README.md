# Walid Zitouni — Portfolio

A simple, responsive cybersecurity portfolio built with React, TypeScript, Vite, and Tailwind CSS.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The site is automatically deployed to GitHub Pages by the workflow in `.github/workflows/deploy.yml` whenever `main` is updated.

## Content

Portfolio content is maintained in `src/App.tsx`; the visual theme is in `src/App.css`. The downloadable CV and favicon are in `public/`.
